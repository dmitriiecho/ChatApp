# Архитектура

[English version](../en/README.md)

ChatApp — демо-чат для Android со своим сервером: вы выбираете, под каким пользователем войти, и получаете список чатов с ботами, которые пишут сами и отвечают вам. Приложение работает без сети: чаты открываются из кэша, сообщение, написанное без сети, уходит, как только она появится, а всё пропущенное подтягивается само. Сервер на Ktor в [`server/`](../../../server/README.ru.md) хранит чаты и рассылает события.

Эти страницы объясняют, как устроено приложение и почему именно так. На каждой — правила, их причины и короткие фрагменты кода проекта.

&nbsp;

## Модули коротко

Приложение разбито на четыре уровня, снизу вверх:

```text
app/           app                                приложение: Koin, навигация, фоновая работа
feature/       login, chats                       по одной фиче в каждом
crossfeature/  domain, data, ui                   код про чаты, нужный двум и более фичам
core/          designsystem, compose-utils,       ничего не знает про чаты
               mvi, network
```

Модуль никогда не зависит от уровня выше своего, и фичи никогда не зависят друг от друга. Оба правила проверяет сборка. Рядом лежат `contract/` с DTO, общими для приложения и сервера, и `server/` — сам сервер.

## Стек

Основные библиотеки и инструменты. Все библиотеки приложения работают и в Kotlin Multiplatform, так что код можно будет туда перенести:

| Область | Выбор |
|---|---|
| Платформа | Android (minSdk 26) |
| Язык и UI | Kotlin 2.4, Jetpack Compose, Material 3 |
| Структура | MVI на собственном ядре (`:core:mvi`) |
| DI | [Koin](https://insert-koin.io) 4.2 на аннотациях; его компиляторный плагин проверяет граф при сборке |
| Навигация | [Navigation 3](https://developer.android.com/guide/navigation/navigation-3) |
| Данные | [Room 3](https://developer.android.com/jetpack/androidx/releases/room3) как кэш, который читают экраны, WorkManager для отправки |
| Сеть | Ktor Client (движок OkHttp) с WebSocket, kotlinx.serialization |
| Сборка | Gradle 9.8, AGP 9.4, JDK 21, convention-плагины; targetSdk 37, compileSdk 37 |
| Сервер | Ktor 3.6 и SQLite |
| Тесты | kotlin.test, AssertK, kotlinx-coroutines-test, Turbine, Ktor MockEngine, Robolectric, Roborazzi с ComposablePreviewScanner |
